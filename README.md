## 🚀 Project Overview

SmartCart AI is a machine learning based customer segmentation and recommendation system designed to help businesses understand customer behavior, optimize marketing strategies, and increase revenue.

This system performs:

* Customer Segmentation using Clustering
* Customer Persona Generation
* AI Marketing Strategy Recommendation
* Customer Lifetime Value Prediction
* Revenue Forecasting
* Interactive Business Dashboard (Streamlit)

---

## 🧠 Machine Learning Concepts Used

* Unsupervised Learning (KMeans Clustering)
* Dimensionality Reduction (PCA)
* Feature Engineering
* Data Preprocessing Pipeline
* Customer Behavior Analytics
